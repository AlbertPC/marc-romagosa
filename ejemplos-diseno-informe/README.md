# Diseños de ejemplo · informe de muestra

Exploración visual basada en `diseno-informe-muestra.md`.

Incluye una vista comparativa y cinco direcciones:

1. Sobrio corporativo
2. Editorial
3. Datos primero
4. Minimalista suizo
5. Cálido y serio

Estas láminas sirven para valorar color, tipografía, retícula y jerarquía. Son bocetos raster generados para escoger una dirección; antes de enviarlos como informe final debe reconstruirse la opción elegida en un formato editorial editable y sustituir cualquier texto abreviado por el contenido literal de la parte A.
